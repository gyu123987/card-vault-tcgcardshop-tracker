# Security and privacy

Card Vault reads installed game files and saves. It stores its own drafts, summary sync history and extracted artwork locally. The server binds to loopback and should not be exposed to the internet.

The desktop launcher requests public release metadata from GitHub on launch. It sends no collection, save, or draft data and never needs your GitHub key. Download links are fixed to this project's releases.

Please use GitHub's private vulnerability reporting if enabled. Otherwise open a minimal issue asking for a private reporting channel; do not publish exploit details, credentials or personal save data.
